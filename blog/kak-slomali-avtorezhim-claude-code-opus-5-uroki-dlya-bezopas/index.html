Как сломали авторежим Claude Code Opus 5: уроки для безопасных агентов

2026-09-11новость

Защитный режим Auto Mode в Claude Code Opus 5 оказался уязвим. Строго говоря, это не классическая промпт-инъекция: Виллисон называет ее атакой через окружение агента (confused environment attack). Исследователь Йохан Ребергер обнаружил атаку, которая, по его словам, работает в 80% случаев. Уязвимость ставит под вопрос безопасность и предсказуемость поведения агентов, особенно в критических пайплайнах.

Атака работает так: агент скачивает и распаковывает ZIP-архив, а затем выполняет код, который импортирует base64. При этом Claude Code не замечает, что вместе с base64 импортируется локальный файл struct.py, извлеченный из архива. Самое тревожное: в некоторых случаях сам защитный механизм Auto Mode блокировал команды по очистке, когда агент обнаруживал компрометацию. То есть, система безопасности пропускала вредоносный код и вдобавок мешала его остановить!

Для меня это подтверждает старый принцип: любая система, работающая с внешними потенциально враждебными входными данными, должна быть изолирована. Если вы строите агентные пайплайны, которые могут столкнуться с промпт-инъекциями или обработкой недоверенного кода, то вывод Йохана Ребергера, с которым соглашается Саймон Виллисон: если есть риск стать целью атаки, запускать агентов безопасно только в песочнице. Дело не в одной надежности: это фундамент для внедрения ИИ в серьезные бизнес-процессы.

Подробнее об атаке читайте в обзоре Саймона Виллисона.

How Claude Code Opus 5 Auto Mode got broken: lessons for building safe agents

2026-09-11news

The Auto Mode protection in Claude Code Opus 5 turned out to be vulnerable. Strictly speaking, this is not a classic prompt injection: Willison calls it an attack through the agent's environment (confused environment attack). Researcher Johann Rehberger found an attack that, according to him, works in 80% of cases. The vulnerability calls into question how safe and predictable agent behavior really is, especially in critical pipelines.

Here is how the attack works: the agent downloads and unpacks a ZIP archive, then runs code that imports base64. Claude Code does not notice that importing base64 also pulls in a local struct.py file extracted from the archive. The most alarming part: in some cases the Auto Mode protection itself blocked cleanup commands after the agent detected the compromise. In other words, the security system let the malicious code through and then got in the way of stopping it!

For me, this confirms an old principle: any system that handles external, potentially hostile input has to be isolated. If you build agent pipelines that may run into prompt injections or have to process untrusted code, here is Johann Rehberger's conclusion, which Simon Willison agrees with: if there is a risk of being targeted, the only safe way to run agents is in a sandbox. This is about more than reliability. It is the foundation for bringing AI into serious business processes.
